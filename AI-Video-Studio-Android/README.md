# AI Video Studio Android

Primera versión de prueba para Android. Incluye editor de guion, voz del sistema en español, selección múltiple de imágenes y MP4, y compartir guion.

**Todavía no exporta un MP4 ni genera imágenes o videos con IA.** Esas funciones deben implementarse y probarse antes de anunciar una versión completa.

## Compilar
Abre el proyecto en Android Studio y ejecuta `gradle assembleDebug`, o usa el workflow de GitHub Actions incluido.
